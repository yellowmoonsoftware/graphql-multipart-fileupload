# Security Policy

## Supported Versions

Security fixes are provided for the latest release in the 2.x line. Users should
upgrade to the latest available 2.x release to receive fixes.

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x and earlier | No |

## Reporting a Vulnerability

Do not report suspected vulnerabilities in a public issue. Use the repository's
[private vulnerability reporting](https://github.com/yellowmoonsoftware/graphql-multipart-fileupload/security)
flow by selecting **Report a vulnerability**.

Include, when possible:

- The affected version and environment.
- A description of the vulnerability and its potential impact.
- Reproduction steps or a proof of concept.
- Known mitigations or suggested fixes.
- Whether the vulnerability has been disclosed elsewhere.

Reports are reviewed on a best-effort basis, with no guaranteed response or
remediation timeline. Maintainers will communicate through the private advisory
and, when a vulnerability is confirmed, coordinate a fix and public disclosure.

Use public GitHub issues for ordinary bugs and other non-sensitive reports.
